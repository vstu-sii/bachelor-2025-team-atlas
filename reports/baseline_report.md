# Baseline-модель AI Pitch Deck Generator — отчёт по качеству

Автор: AI Engineer  
Дата: 10.12.2025  
Версия: 0.1

---

## 1. Конфигурация эксперимента

- Модель LLM: `gpt-4.1-mini` (через API OpenAI).
- Температура: 0.4
- Язык дека: английский.
- Количество слайдов (таргет): 10–11 (в зависимости от стартапа).
- Датасет:
  - `data/processed/eval_dataset.json`
  - 3 стартапа: GreenFleet, MedAI Triage, SubSync.
- Код эксперимента:
  - `ml/evaluation/evaluate_baseline.py`
  - Метрики: `ml/evaluation/metrics.py`
  - Галлюцинации (числа): `ml/evaluation/hallucination.py`

---

## 2. Используемые метрики

1. **Структурные:**
   - `slide_count` — количество слайдов в сгенерированном деке.
   - `slide_count_ok` — попадает ли количество слайдов в диапазон (таргет ± 2).
   - `section_coverage` — доля обязательных секций (Problem, Solution, Market, Business Model, Team, Ask), которые присутствуют в дека.

2. **Текстовые:**
   - `bleu` — BLEU между эталонным и сгенерированным деком.
   - `rouge_l_f` — ROUGE-L F-measure между эталонным и сгенерированным деком.

3. **Галлюцинации:**
   - `numeric_hallucinations` — количество чисел, которых нет ни в брифе, ни в эталоне.
   - `has_numeric_hallucinations` — бинарный индикатор (0/1).

---

## 3. Сводные результаты baseline

(значения берутся из `ml/evaluation/results/baseline_metrics.json`)

Пример формата:

- Среднее покрытие секций (`section_coverage`): **0.85**
- Доля дека с нормальным количеством слайдов (`slide_count_ok`): **1.00**
- Средний BLEU (`bleu`): **0.30**
- Средний ROUGE-L (`rouge_l_f`): **0.45**
- Среднее количество числовых галлюцинаций (`numeric_hallucinations`): **0.0**
- Доля кейсов с числовыми галлюцинациями (`has_numeric_hallucinations`): **0.0**

---

## 4. Качественный анализ

1. **Сильные стороны baseline:**
   - В большинстве случаев присутствуют ключевые секции (Problem, Solution, Market, Business Model, Team, Ask).
   - Структура дека близка к эталонной по количеству слайдов.
   - Стиль текста достаточно деловой и пригоден для чтения инвестором.

2. **Основные проблемы:**
   - Слабое соответствие формулировок эталонным (BLEU/ROUGE умеренные).
   - Иногда недостаточно подробно раскрываются Market / Traction.
   - Возможны общие формулировки без конкретики (чтобы избегать галлюцинаций).

3. **Наблюдения по галлюцинациям:**
   - Простая проверка чисел показывает низкий уровень “левых” цифр.
   - Модель осторожна с конкретными числовыми показателями, если их нет во входе.

---

## 5. План улучшений

1. **RAG по примерам питч-деков:**
   - Добавить поиск похожих деков по индустрии/стадии.
   - Подмешивать лучшие примеры в промпт, чтобы усилить структуру и конкретику.

2. **Тюнинг промптов:**
   - Чётче задавать формат для каждого раздела (Problem, Solution, Market и т.д.).
   - Ограничивать количество “воды” и требовать конкретики, если она есть во входных данных.

3. **Расширение датасета:**
   - Добавить больше эталонных деков (10–20 стартапов).
   - Ввести ручную разметку по галлюцинациям (не только числа).

4. **Подбор модели:**
   - Сравнить несколько моделей (например, `gpt-4.1-mini` vs более лёгкая/дешёвая).
   - Зафиксировать trade-off между стоимостью и качеством.

---

## 6. Вывод

Baseline-модель уже решает основную задачу: по краткому описанию стартапа генерирует структурированный питч-дек, близкий к эталонному по разделам и структуре.  
При этом остаётся резерв по улучшению содержания (BLEU/ROUGE) и управлению детализацией за счёт RAG и более строгого промпт-дизайна.
