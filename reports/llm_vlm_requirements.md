# Анализ требований к LLM / VLM – AI Pitch Deck Generator

## 1. Обзор кейса

Система генерирует **pitch deck стартапа** на основе:

- Структурированного **брифа основателя** (форма / стенограмма интервью)
- Опционально: **документов компании** (сайт, one-pager, Notion, PDF и т.д.)
- Опционально: уже существующих слайдов / брендбука (для анализа через VLM)

Выход:

- **Нормализованное JSON-представление** презентации (слайды с заголовками, целями, буллетами, описаниями визуалов)
- В следующих этапах проекта — экспорт в PPTX / Keynote / HTML

---

## 2. Функциональные требования к LLM

### 2.1. Вход и контекст

Модель должна уметь:

- Обрабатывать **длинный контекст**:
  - Бриф основателя (1–3 страницы текста)
  - Дополнительные материалы (до 10–15k токенов суммарно)
- Поддерживать **многошаговый диалог**:
  - Уточняющие вопросы по бизнес-модели, метрикам и т.п.
  - Итеративное улучшение:  
    например, «сделай слайд Traction более агрессивным, но реалистичным»

### 2.2. Формат вывода

Модель должна возвращать **структурированный JSON** стабильной схемы:

```json
{
  "slides": [
    {
      "index": 1,
      "title": "Problem",
      "goal": "Объяснить ключевую боль...",
      "key_points": ["...", "..."],
      "visuals_description": "..."
    }
  ]
}
