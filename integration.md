# План Спринта — AutoPitch Deck Generator
## MLOPS (Infrastructure / AI Pipeline)
    • Развернуть рабочий backend (FastAPI + Celery) и интегрировать с базой данных (PostgreSQL).
    • Контейнеризовать все сервисы в docker-compose (Backend, Frontend, AI Parser, LLM API).
    • Настроить мониторинг работы сервисов через Prometheus / Grafana.
    • Подготовить инструкции по запуску всей системы через Docker.

## AI ENGINEER (LLM / AI Parser Integration)
    • Интегрировать AI Parser для извлечения текста и структуры слайдов из PPTX/PDF.
    • Настроить LLM API для оптимизации и генерации текста слайдов.
    • Разработать промпты для генерации ключевых смыслов и структуры новой презентации.
    • Реализовать endpoint /optimize_presentation для улучшения существующих презентаций.
    • Реализовать endpoint /generate_from_scratch для создания презентации с нуля.

## FULLSTACK ENGINEER (Integration & Features)
    • Реализовать аутентификацию через Telegram и управление пользователями.
    • Подключить фронтенд к backend для загрузки файлов и отображения проектов.
    • Интегрировать предпросмотр презентации с визуализацией структуры и текста.
    • Применить базовый шаблон дизайна (цвета, шрифты, сетка).
    • Реализовать экспорт презентации в PPTX и PDF.
    • Настроить автосохранение версий презентации.

## Приоритизация задач
    1. Аутентификация + хранение пользователей (обязательная база для всех функций).
    2. Загрузка PPTX/PDF и сохранение файлов (необходимо для парсинга).
    3. Парсинг презентаций (AI Parser) — извлечение структуры и текста.
    4. Оптимизация текста через LLM (ключевое ядро функционала).
    5. Применение базового шаблона дизайна.
    6. Предпросмотр презентации (React canvas/SVG).
    7. Экспорт PPTX/PDF.
    8. Генерация презентации с нуля (опционально, вторично).
    9. Расширенные шаблоны дизайна и редактирование слайдов (MVP не включает).
    10. Интеграция с внешними сервисами (Figma, облако) — опционально.

## Roadmap до завершения MVP
### Спринт 1 (1 неделя): Основы системы
    • Архитектурная схема (C4) и финализация требований.
    • Настройка репозиториев и базы данных.
    • Реализация аутентификации Telegram.
    • Базовый UI: вход/регистрация, дашборд.
    • MVP: частично.
### Спринт 2 (1 неделя): Загрузка и хранение файлов
    • Модуль загрузки презентаций.
    • Валидация и ограничение размера файлов (до 100 МБ).
    • Интеграция с облачным хранилищем.
    • Создание очередей Celery для обработки файлов.
    • UI: экран загрузки презентации.
    • MVP: да.
### Спринт 3 (1 неделя): AI Parser
    • Извлечение текста из PDF (PDFMiner / PyMuPDF).
    • Парсинг PPTX (python-pptx).
    • Выделение структуры слайдов (заголовки/блоки/списки).
    • API выдаёт JSON со структурой презентации.
    • Логирование и обработка ошибок.
    • MVP: да.
### Спринт 4 (1 неделя): Оптимизация текста
    • Связка с LLM API (OpenAI / Anthropic).
    • Алгоритм сокращения текста и выделения ключевых смыслов.
    • API: /optimize_presentation.
    • UI: предпросмотр текста.
    • MVP: критически важно.
### Спринт 5 (1 неделя): Генерация презентации с нуля
    • LLM-промпты для структуры 10–12 слайдов.
    • Генерация контента по разделам (Проблема, Решение, Продукт, Команда).
    • Объединение в JSON-структуру.
    • API: /generate_from_scratch.
    • UI: форма ввода описания стартапа.
    • MVP: вторично.
### Спринт 6 (1 неделя): Дизайн и стили
    • JSON-описание шаблонов дизайна.
    • Применение цветов, шрифтов, сетки.
    • Автоматическое распределение элементов по слайду.
    • UI: выбор шаблона.
    • MVP: минимальный шаблон — да.
### Спринт 7 (1 неделя): Предпросмотр и редактор
    • Web-просмотр слайдов (React canvas/SVG).
    • Редактирование текста, цветов и блоков.
    • Автосохранение версий.
    • MVP: базовый предпросмотр — да.
### Спринт 8 (1 неделя): Экспорт
    • Генерация PPTX (python-pptx).
    • Генерация PDF (reportlab или экспорт из PPTX).
    • Финальный workflow: загрузил → оптимизировал → скачал.
    • Нагрузочное тестирование.
    • MVP: да.

Критерии завершения MVP
    • Регистрация и вход через Telegram.
    • Архитектура Core Service + AI Parser + LLM API.
    • Загрузка презентаций (.pptx / .pdf).
    • Парсинг и извлечение структуры слайдов.
    • Оптимизация текста через LLM.
    • Один базовый шаблон дизайна.
    • Простая предпросмотрная визуализация.
    • Экспорт PPTX/PDF.
## Риски и миграция
| Риск | Митигация |
|------|-----------|
| Долгое время рендеринга шаблонов | Предварительная генерация CSS-шаблонов, оптимизация SVG |
| Нестабильный парсинг PDF | Fallback: OCR, упрощённый режим без сохранения изображений |
| Непредсказуемость LLM | Жёсткие промпт-шаблоны, ограничения температуры |
| Проблемы экспорта PPTX | Ограничение стилей в MVP, модульные компоненты слайдов |
