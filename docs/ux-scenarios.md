# Детальные UX-сценарии пользовательских потоков
  AutoPitch Deck Generator
  
## 1. Регистрация и вход 

### Happy Path
**Пользовательский контекст**: Предприниматель хочет быстро начать создание презентации для инвесторов

| Шаг	| Действие	| Системный ответ	| Микроинтеракции	| Техническая реализация |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| Открывает главную страницу	| Показывает hero-секцию с примерами презентаций и CTA "Создать питч"	| Плавная анимация трансформации слайдов-примеров	| WebGL/Canvas анимация |
|2	| Кликает "Начать бесплатно"	| Открывает  Widget в модальном окне	| Затемнение фона, плавное появление виджета с тенью	| React Modal + Framer Motion |
|3	| Подтверждает авторизацию 	| Показывает индикатор загрузки "Создаем ваш профиль..."	| Анимация спиннера с логотипом + прогресс-круг	| Lottie animation |
|4	| -	| Перенаправляет в дашборд с welcome-tour	| Плавный переход с fade-эффектом, highlight новых функций	| React Router + guided tour |

### Edge Cases
- **Автоматический вход**: При активной сессии - мгновенный redirect в дашборд

- **Повторная регистрация**: Toast-уведомление "Добро пожаловать назад!" с показом последнего проекта

### Обработка ошибок
- ** Widget недоступен**:

- Показ fallback: форма ввода  username

- Кнопка "Повторить" с таймером 5 сек


## 2. Загрузка существующей презентации для улучшения (UC1)

### Happy Path
Пользовательский контекст: У предпринимателя есть черновая презентация, нужно сделать её профессиональной

|Шаг	| Действие	| Системный ответ	| LLM взаимодействия	| Визуальная обратная связь |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| В дашборде нажимает "Улучшить презентацию"	| Открывает drag-and-drop зону для файлов	| -	| Выделение зоны при hover, анимация иконки файла |
|2	| Перетаскивает PPTX/PDF файл (≤100MB)	| Показывает превью файла + кнопку "Анализировать"	| -	| Progress bar загрузки, валидация формата в реальном времени |
|3	| Нажимает "Анализировать"	| Показывает прогресс-бар с 3 этапами:	| -	| Анимированный progress bar с иконками этапов |
|4	| -	| Этап 1: Парсинг структуры (0-30%)	| -	| Иконка "разбора" с пульсацией |
|5	| -	| Этап 2: AI-анализ контента (30-70%)	| LLM: "Анализирую тексты слайдов, ищу ключевые тезисы, определяю структуру"	| Текстовый поток: "Нашел 12 слайдов... Анализирую слайд 'Проблема рынка'..." |
|6	| -	| Этап 3: Рекомендации по улучшению (70-100%)	| LLM: "Слайд 3 слишком перегружен. Слайд 7 не хватает метрик. Слайд 9: отличный контент!"	| Постепенное появление рекомендаций в sidebar |
|7	| -	| Открывает редактор с исходной и улучшенной версиями side-by-side	| LLM: Сгенерированные улучшенные тексты для каждого слайда	| Split-view редактор, highlight изменений |

### Микроинтеракции
- Drag-and-drop: Подсветка зоны, анимация сброса файла

- Парсинг в реальном времени: Показ количества найденных слайдов по мере обработки

- AI-рекомендации: Интерактивные карточки с кнопками "Принять", "Отклонить", "Редактировать"

- Side-by-side сравнение: Кнопка "Показать различия" с highlight изменений

## 3. Создание презентации с нуля (UC2)
### Happy Path

Пользовательский контекст: У предпринимателя есть идея, но нет презентации

|Шаг	| Действие	| Системный ответ	| LLM взаимодействия	|  UX Patterns |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| Нажимает "Создать с нуля"	| Открывает step-by-step мастер на 5 шагов	| -	| Прогресс-индикатор вверху, понятный back/next |
| 2	| Шаг 1: Описание идеи (текстовое поле)	| Валидация минимальной длины, подсказки примеров	| LLM: Анализ введенного текста, генерация уточняющих вопросов	| Интерактивные подсказки, примеры успешных pitch |
|3 |	Шаг 2: Ключевые разделы (чековый список)	| Предлагает стандартную структуру питча	| LLM: "Для SaaS-стартапа рекомендую добавить слайд 'Unit Economics'"	| Smart suggestions на основе индустрии |
|4	| Шаг 3: Целевая аудитория	| Multiple select + текстовое поле	| LLM: "Для B2B-инвесторов добавить слайд 'Sales Pipeline'"	 | Персонализированные рекомендации |
|5	| Шаг 4: Выбор шаблона дизайна	| Галерея превью с фильтрами по стилю	| LLM: "Для deep-tech подходит шаблон 'Venture', для e-commerce | - | 'Modern'"	AI-рекомендация выделена "Рекомендовано AI" |
|6	| Шаг 5: Предпросмотр и настройка	| Генерирует первый черновик	| LLM: Генерирует контент для всех выбранных слайдов	| Скелетон-скрины → постепенное наполнение |
|7	| Нажимает "Создать презентацию"	| Открывает редактор с готовым черновиком	| -	| Celebration анимация при завершении |

### Динамическое взаимодействие
- **Контекстная помощь**: Tooltips с примерами для каждого поля

- **Прогрессивное раскрытие**: Сложные опции скрыты под "Расширенные настройки"

- **Instant preview**: Мини-превью изменяется при выборе шаблона

## 4. Настройка дизайна и стиля (UC3)
### Happy Path

**Пользовательский контекст**: Презентация готова по содержанию, нужно улучшить визуал

|Шаг	| Действие	| Системный ответ	| Дизайн-система	|  Визуальная обратная связь |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| В редакторе нажимает "Дизайн"	| Открывает панель дизайна справа  | -	| Плавное выдвижение панели |
|2	| Выбирает шаблон из галереи	| Мгновенно применяет ко всем слайдам	| Design Engine: Пересчет layout, размеров шрифтов	| Instant preview, анимация перехода |
|3	| Настраивает цветовую схему	| Color picker + предустановленные палитры	| AI: "Эти цвета соответствуют брендингу SaaS-компаний"	| Live preview на активном слайде |
|4	| Регулирует плотность контента (Compact/Normal/Spacious)	| Перераспределяет элементы на слайдах	|  Автоматический пересчет отступов	|  Анимация "раздвижения" элементов |
|5	| Нажимает "Применить ко всем слайдам"	| Синхронизирует изменения	| Batch update всех слайдов	| Toast: "Дизайн применен к 12 слайдам" |
|6	| Кликает на отдельный элемент для тонкой настройки	| Показывает контекстное меню с опциями	| Element-specific controls	| Highlight выбранного элемента |

### Профессиональные фичи
- Brand Kit: Загрузка логотипа, выбор фирменных шрифтов

- AI-рекомендации по дизайну: "Для слайда с финансовыми показателями рекомендуем использовать диаграмму вместо таблицы"

- Консистентность: Автоматическая проверка единообразия стилей

## 5. Экспорт и публикация

### Happy Path

**Пользовательский контекст**: Презентация готова, нужно поделиться с инвесторами

|Шаг	| Действие	| Системный ответ	| Форматы	| Особенности |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| Нажимает "Экспорт"	| Модальное окно с вариантами экспорта	| -	| Четкая иконография каждого формата |
|2	| Выбирает "PPTX для редактирования"	| Прогресс генерации файла	| Полностью редактируемый PowerPoint	| Индикатор: "Добавляю анимации... Оптимизирую изображения..." |
|3	| -	|  Предлагает скачать или сохранить в облако	| -	| Кнопки: "Скачать", "Сохранить в Google Drive", "Отправить на email"  |
|4	| Выбирает "PDF для рассылки"	| Опции качества и сжатия	| Print-ready PDF с гиперссылками	| Предпросмотр первой страницы PDF |
|5	| Нажимает "Экспорт в обеих версиях"	| Фоновая обработка, уведомление о готовности	| PPTX + PDF в zip-архиве	| Push-уведомление при завершении |

### Дополнительные сценарии
- Быстрый экспорт: 1-кликовый экспорт с настройками по умолчанию

- Публикация ссылкой: Генерация защищенной ссылки для просмотра в браузере

- Печать: Оптимизация для A4/Letter форматов

## Системные микроинтеракции
### Уведомления и обратная связь
- Success: Green toast с иконкой  и понятным действием

- Warning: Yellow toast с иконкой  и рекомендацией

- Error: Red toast с иконкой , объяснением и кнопкой "Повторить"

- AI Progress: Специальные тосты для AI-операций с прогрессом

### Состояния загрузки
- Skeleton screens для редактора презентаций

- Прогресс с этапами для длительных операций (парсинг, генерация, экспорт)

- Optimistic updates для быстрых действий (изменение текста, цвета)

### Визуальные переходы
- Fade-in/out между страницами дашборда

- Slide animations для переключения слайдов в редакторе

- Chart animations для появления графиков и диаграмм

- Physics-based animations для drag-and-drop элементов
