# Детальные UX-сценарии пользовательских потоков
  AutoPitch Deck Generator
  
## 1. Регистрация и вход через Telegram

### Happy Path
**Пользовательский контекст**: Предприниматель хочет быстро начать создание презентации для инвесторов

| Шаг	| Действие	| Системный ответ	| Микроинтеракции	| Техническая реализация |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| Открывает главную страницу	| Показывает hero-секцию с примерами презентаций и CTA "Создать питч"	| Плавная анимация трансформации слайдов-примеров	| WebGL/Canvas анимация |
|2	| Кликает "Начать бесплатно"	| Открывает Telegram Widget в модальном окне	| Затемнение фона, плавное появление виджета с тенью	| React Modal + Framer Motion |
|3	| Подтверждает авторизацию в Telegram	| Показывает индикатор загрузки "Создаем ваш профиль..."	| Анимация спиннера с логотипом + прогресс-круг	| Lottie animation |
|4	| -	| Перенаправляет в дашборд с welcome-tour	| Плавный переход с fade-эффектом, highlight новых функций	| React Router + guided tour |

### Edge Cases
- **Автоматический вход**: При активной сессии - мгновенный redirect в дашборд

- **Повторная регистрация**: Toast-уведомление "Добро пожаловать назад!" с показом последнего проекта

### Обработка ошибок
- **Telegram Widget недоступен**:

- Показ fallback: форма ввода Telegram username

- Кнопка "Повторить" с таймером 5 сек

- Альтернатива: "Продолжить как гость" (ограниченный функционал)

## 2. Загрузка существующей презентации для улучшения (UC1)

### Happy Path
Пользовательский контекст: У предпринимателя есть черновая презентация, нужно сделать её профессиональной

|Шаг	| Действие	| Системный ответ	| LLM взаимодействия	| Визуальная обратная связь |
|-----|-----------|--------------------------|--------------------------|-------------|
|1	| В дашборде нажимает "Улучшить презентацию"	| Открывает drag-and-drop зону для файлов	| -	| Выделение зоны при hover, анимация иконки файла |
|2	| Перетаскивает PPTX/PDF файл (≤100MB)	| Показывает превью файла + кнопку "Анализировать"	| -	| Progress bar загрузки, валидация формата в реальном времени |
|3	| Нажимает "Анализировать"	| Показывает прогресс-бар с 3 этапами:	| -	| Анимированный progress bar с иконками этапов |
|4	| -	| Этап 1: Парсинг структуры (0-30%)	| -	| Иконка "разбора" с пульсацией |
|5	| -	| Этап 2: AI-анализ контента (30-70%)	| LLM: "Анализирую тексты слайдов, ищу ключевые тезисы, определяю структуру"	| Текстовый поток: "Нашел 12 слайдов... Анализирую слайд 'Проблема рынка'..." |
|6	| -	| Этап 3: Рекомендации по улучшению (70-100%)	| LLM: "Слайд 3 слишком перегружен. Слайд 7 не хватает метрик. Слайд 9: отличный контент!"	| Постепенное появление рекомендаций в sidebar |
|7	| -	| Открывает редактор с исходной и улучшенной версиями side-by-side	| LLM: Сгенерированные улучшенные тексты для каждого слайда	| Split-view редактор, highlight изменений |

### Микроинтеракции
- Drag-and-drop: Подсветка зоны, анимация сброса файла

- Парсинг в реальном времени: Показ количества найденных слайдов по мере обработки

- AI-рекомендации: Интерактивные карточки с кнопками "Принять", "Отклонить", "Редактировать"

- Side-by-side сравнение: Кнопка "Показать различия" с highlight изменений
