# AutoPitch Deck Generator API

API для автоматической генерации и улучшения питч-презентаций стартапов.

## Назначение API
AutoPitch Deck Generator API — это сервис для автоматического создания и оптимизации презентаций для стартапов. Позволяет предпринимателям быстро создавать профессиональные питч-деки без дизайнерских навыков.

## Основные возможности
### 1. Аутентификация
  - Регистрация/вход  

  - Использует Login Widget

  - Возвращает JWT-токены (access + refresh)

  - Rate limiting: 10 запросов за 15 минут

  - Обновление токена (POST /auth/refresh)

  - Получение новой пары токенов по refresh-токену

  - Выход из системы (POST /auth/logout)

  - Инвалидация текущего токена

  - Требует Bearer-аутентификацию

### 2. Управление проектами
  -  Список проектов (GET /projects)

  - Пагинация (до 50 на страницу)

  - Фильтрация по статусу

  - Сортировка по дате создания/обновления

  -Создание проекта (POST /projects)

  - Создание пустого проекта или с загруженным файлом

  - Указание индустрии и языка

  - Детали проекта (GET /projects/{id})

  - Полная информация о проекте

  - История версий презентации

  - Обновление проекта (PUT /projects/{id})

  - Изменение названия, описания, настроек

  - Удаление проекта (DELETE /projects/{id})

  - Каскадное удаление всех связанных данных

### 3. Работа с файлами
  - Загрузка презентации (POST /projects/{id}/upload)

  - Поддержка PPTX и PDF

  - Максимальный размер: 100MB

  - Автоматический запуск парсинга

  - История версий (GET /projects/{id}/versions)

  - Все версии презентации в проекте

  - Возможность восстановления

### 4. AI-операции
  - Парсинг презентации (автоматически после загрузки)

  - Извлечение текста и структуры

  - Определение типа слайдов

  - Оптимизация контента (в разработке)

  - Сокращение текста через LLM

  -  Улучшение формулировок

  - Генерация с нуля (в разработке)

  - Создание структуры по описанию стартапа

### 5. Экспорт
  - Экспорт презентации (в разработке)

  - Форматы: PPTX, PDF

  - Разные качество настроек

## Как работает
Основной workflow:
1.Регистрация → Пользователь входит через сайт

2.Создание проекта → Новый проект или загрузка существующей презентации

3.Загрузка файла → PPTX/PDF → автоматический парсинг

4.AI-обработка → Оптимизация текста, структурирование

5.Дизайн → Применение профессионального шаблона

6.Экспорт → Скачивание готовой презентации

### Технические особенности
  - RESTful API с JSON форматом

  - Bearer JWT-аутентификация

  - Асинхронные операции для долгих задач (парсинг, генерация)

  - Версионность всех изменений

  - Rate limiting на критические эндпоинты

  - Поддержка CORS

### Статусы ответов
200 - Успешный запрос

201 - Ресурс создан

202 - Задача принята в обработку

400 - Невалидные данные

401 - Неавторизованный доступ

404 - Ресурс не найден

409 - Конфликт (например, дубликат)

413 - Превышен размер файла

422 - Ошибка валидации

429 - Слишком много запросов

500 - Внутренняя ошибка сервера

### Примеры использования
```bash
#Аутентификация 
curl -X POST https://api.autopitch.com/v1/auth/authorization \
  -H "Content-Type: application/json" \
  -d '{
    "id": 123456789,
    "username": "ivan_startup",
    "auth_date": 1600000000,
    "hash": "abc123..."
  }'

# Создание нового проекта
curl -X POST https://api.autopitch.com/v1/projects \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Мой AI стартап",
    "description": "Генерация питч-деков для предпринимателей",
    "industry": "saas",
    "language": "ru"
  }'

# Получение списка проектов
curl -X GET "https://api.autopitch.com/v1/projects?page=1&limit=10&status=ready" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
