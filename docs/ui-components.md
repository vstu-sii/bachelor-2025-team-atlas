## 0. Экран Главное меню

- Название экрана: Главное меню
- Назначение: Предпросмотр главное страницы.

**Макет**:

- Hero-секция с фоновым градиентом и примерами презентаций

- Центрированная карточка авторизации с закруглёнными углами

- Футер с информацией о системе

**Элементы**:

- Логотип: "AutoPitch" в верхней части hero-секции

- Widget: Кнопка "Войти бесплатно "

## 1. Экран Авторизации

-   **Название экрана**: Авторизация
-   **Назначение**: Интерфейс для входа пользователя.
-   **Макет**:
    -   Центрированный прямоугольный блок с закруглёнными углами.
    -   Заголовок: "Авторизация" в верхней части.
-   **Элементы**:
    -   **Поле ввода 1**: Плейсхолдер "Email" (предназначено для ввода email ).
    -   **Поле ввода 2**: Плейсхолдер "Password" (предназначено для ввода пароля).
    -   **Кнопка**: "Продолжить!" (чёрный фон, белый текст), расположена под полями ввода, служит для отправки формы.
    -   **Текстовая ссылка**: "Нет аккаунта?" под кнопкой, вероятно, для перехода к регистрации.
-   **Поведение**:
    -   Пользователь вводит учётные данные в поля.
    -   Нажатие на "Продолжить!" запускает процесс авторизации.
    -   Ссылка "Нет аккаунта?" перенаправляет на страницу регистрации (предполагается).
