# ROADMAP проекта AutoPitch Deck Generator

## Эпики и структура спринтов

### Эпик 1. Базовая инфраструктура и ядро приложения

Цель: запустить фундамент: аутентификация, БД, базовый фронтенд, загрузка файлов.

### Спринт 1 (Недели 1–2): Основы системы

Задачи:

Архитектурная схема (C4) и финализация требований

Настройка репозиториев, CI/CD

Настройка FastAPI backend + PostgreSQL

Имплементация аутентификации (Telegram Widget / email-auth)

Структура БД: пользователи, проекты, файлы

Базовый UI: вход/регистрация, дашборд
Зависимости: нет
MVP: частично

Эпик 2. Модуль загрузки и парсинга презентаций (AI Parser)

Цель: загрузка .pptx/.pdf и извлечение текста, изображений, структуры.

Спринт 2 (Недели 3–4): Загрузка и хранение файлов

Задачи:

Модуль загрузки презентаций

Валидация и ограничение размера (до 100 МБ)

Интеграция с облачным хранилищем (Google Drive API)

Создание очередей Celery для обработки файлов

UI: экран загрузки
Зависимости: Эпик 1
MVP: да

Спринт 3 (Недели 5–6): AI Parser

Задачи:

Извлечение текста из PDF (PDFMiner / PyMuPDF)

Парсинг PPTX (python-pptx)

Выделение структуры слайдов (хедеры/блоки/списки)

API выдаёт JSON со структурой

Логирование и обработка ошибок
Зависимости: Спринт 2
MVP: да

Эпик 3. LLM-оптимизация контента / генерация текста

Цель: улучшение и сокращение входящей презентации + генерация структуры для новой.

Спринт 4 (Недели 7–8): Обработка текста существующей презентации

Задачи:

Связка с LLM-API (OpenAI / Anthropic)

Алгоритм сокращения текста

Логика “ключевых смыслов”

API: /optimize_presentation

UI: предпросмотр текста
Зависимости: Спринт 3
MVP: критически важно

Спринт 5 (Недели 9–10): Генерация презентации с нуля

Задачи:

LLM-промпты для структуры 10–12 слайдов

Генерация контента по разделам (Проблема, Solution, Team и т.д.)

Объединение в JSON-структуру

API: /generate_from_scratch

UI: форма ввода описания стартапа
Зависимости: Спринт 4
MVP: вторично (опционально, если сроки сжаты)

Эпик 4. AI Design Engine — визуальный стиль, рендеринг, экспорт

Цель: применение шаблонов дизайна, рендеринг предпросмотра, экспорт PPTX/PDF.

Спринт 6 (Недели 11–12): Дизайн и стили

Задачи:

JSON-описание шаблонов дизайна

Применение стилей: цвета, шрифты, сетка

Автоматическое распределение элементов по слайду

UI: выбор шаблона
Зависимости: Спринты 3–4
MVP: минимальный шаблон — да

Спринт 7 (Недели 13–14): Рендеринг предпросмотра + редактор

Задачи:

Web-просмотр слайдов (React canvas or SVG)

Редактирование текста в интерфейсе

Изменение цвета/шрифтов/блоков

Автосохранение версии
Зависимости: Спринт 6
MVP: базовый предпросмотр — да
MVP редактор: опционально

Спринт 8 (Недели 15–16): Экспорт

Задачи:

Генерация PPTX (python-pptx)

Генерация PDF (reportlab или экспорт из PPTX)

Финальный workflow: загрузил → оптимизировал → скачал

Нагрузочное тестирование
Зависимости: Спринт 6–7
MVP: да

🔥 MVP-функции (только самое важное)
📌 MVP обязательно включает:

Аутентификация + хранение пользователей

Загрузка PPTX/PDF

Парсинг и извлечение структуры

Оптимизация текста через LLM

Один базовый шаблон дизайна

Простая предпросмотрная визуализация

Экспорт PPTX/PDF

❌ MVP НЕ включает:

Генерация презентации “с нуля”

Расширенные шаблоны дизайна

Интерфейс полного редактирования слайдов

Интеграции с Figma

Сложная коллаборация
