# Документация по схеме базы данных
## AutoPitch Deck Generator

## Обзор

Эта база данных поддерживает систему автоматической генерации и улучшения питч-презентаций для стартапов. Система интегрируется с Telegram для аутентификации, использует AI (LLM) для оптимизации контента, управляет профессиональными шаблонами дизайна и обеспечивает экспорт в различные форматы.

## Связи между таблицами

##Детальные спецификации таблиц
### 1. Таблица Users (Пользователи)
**Назначение**: Хранение учетных записей пользователей, аутентифицированных через Telegram Widget

|Поле	| Тип	| Описание | Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|telegram_id |  BIGINT | Уникальный | идентификатор пользователя Telegram	Первичный ключ аутентификации (UC1, UC2) |
|telegram_username | VARCHAR(255)	| Имя пользователя Telegram с @	| Идентификация пользователя |
|telegram_first_name	| VARCHAR(255)	| Имя пользователя |	Отображение в интерфейсе |
|subscription_tier | ENUM	| Уровень подписки (free/pro/business)	| Определение лимитов и функциональности |
|projects_limit	| INT	| Максимальное количество проектов	| Ограничение по подписке |
|export_limit_daily	| INT	| Дневной лимит экспортов	| Контроль использования |
|created_at	| TIMESTAMP	| Время создания аккаунта	| Аналитика пользователей |
|last_login	| TIMESTAMP	| Последний успешный вход	|  Управление сессиями |
|settings	| JSON	| Настройки пользователя	| Персонализация интерфейса |

**Индексы**:

  - idx_telegram_id - Быстрый поиск пользователей при аутентификации

  - idx_subscription_tier - Фильтрация по уровню подписки

  - idx_created_at - Аналитика роста пользователей

**Связанные сценарии использования**:

  - UC1: Загрузка презентации для улучшения

  - UC2: Создание новой презентации с нуля

  - UC3: Настройка стиля

### 2. Таблица Projects (Проекты)
**Назначение**: Управление презентационными проектами пользователей

|Поле	| Тип	| Описание	| Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|id	| CHAR(36)	| UUID проекта	| Безопасная идентификация проекта  |
|title	| VARCHAR(255)	| Название проекта	| Отображение в интерфейсе |
|status	| ENUM	| Статус проекта (draft → ready → exported)	| Отслеживание прогресса (UC1, UC2) |
|template_id	| VARCHAR(100)	| Используемый шаблон дизайна	| Применение стиля (UC3) |
|industry	| VARCHAR(100)	| Индустрия стартапа	| AI-рекомендации по шаблонам |
|language	| ENUM	| Язык презентации (ru/en)	| Локализация контента  |
|visibility	|  ENUM	| Видимость проекта	| Контроль доступа |
|last_exported_at	|  TIMESTAMP	| Время последнего экспорта	| История активности |

**Ограничения**:

- Внешний ключ на Users с каскадным удалением
- Статус проходит через определенный workflow

**Индексы**:

- idx_user_id - Быстрая загрузка проектов пользователя

- idx_status - Фильтрация по статусу проекта

- idx_created_at - Сортировка по времени создания

- idx_user_status - Эффективные запросы "проекты пользователя со статусом X"

**Связанные сценарии использования**:

- UC1: Загрузка презентации для улучшения

- UC2: Создание новой презентации с нуля

- C3: Настройка стиля

### 3. Таблица PresentationFiles (Файлы презентаций)
**Назначение**: Версионное хранение файлов презентаций и их метаданных

|Поле	| Тип	| Описание	| Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|version_number	| INT	| Номер версии файла	| Управление историей изменений |
|file_type	| ENUM	| Формат файла (pptx/pdf)	| Определение парсера (UC1) |
|source_type	| ENUM	| Источник файла (upload/generated/imported)	| Отслеживание происхождения |
|file_size	| BIGINT |	Размер файла в байтах	| Контроль лимитов (≤100MB) |
|storage_path	| VARCHAR(500)	| Путь в облачном хранилище	| Доступ к файлам |
|parsing_status	| ENUM	| Статус парсинга	| Отслеживание процесса обработки |
|md5_hash	| CHAR(32)	| Хэш содержимого файла	| Обнаружение дубликатов |

**Ограничения**:

- unique_project_version - Уникальная версия в рамках проекта

- Внешний ключ на Projects с каскадным удалением

**Индексы**:

- idx_project_id - Быстрый доступ к файлам проекта

- idx_parsing_status - Мониторинг статусов обработки

- idx_upload_date - Сортировка по времени загрузки

**Связанные сценарии использования**:

- UC1: Загрузка презентации для улучшения (основная таблица)

- UC2: Создание новой презентации с нуля (хранение сгенерированных файлов)

### 4. Таблица Slides (Слайды)
**Назначение**: Хранение структуры и контента отдельных слайдов

|Поле	| Тип	| Описание	| Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|slide_number	| INT	|  Порядковый номер слайда	| Структура презентации |
|slide_type	| ENUM	| Тип слайда (title/problem/solution/market/etc.)	| AI-обработка и дизайн |
|original_content	| JSON	| Контент до оптимизации	| Сохранение исходных данных |
|optimized_content	| JSON	| Контент после LLM-оптимизации	| Результат AI-обработки (UC1, UC2) |
|applied_template	| JSON	| Примененный шаблон оформления	| Дизайн-информация (UC3) |
|ai_feedback	| TEXT	| Комментарии ИИ по улучшению	| Обоснование изменений |
|is_modified	| BOOLEAN | Было ли вручную изменено | Отслеживание ручных правок |

**Ограничения**:

- unique_slide_version - Уникальный слайд в рамках версии файла

- Внешние ключи на Projects и PresentationFiles

**Индексы**:

- idx_project_version - Эффективный доступ к слайдам версии

- idx_slide_type - Фильтрация по типу слайда

- idx_slide_number - Правильная сортировка слайдов

**Связанные сценарии использования**:

- UC1: Загрузка презентации для улучшения (контент слайдов)

- UC2: Создание новой презентации с нуля (генерация слайдов)

- UC3: Настройка стиля (применение шаблонов)

### 5. Таблица AI_Operations (AI-операции)
**Назначение**: Аудит всех AI-операций системы

|Поле	| Тип	| Описание	| Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|operation_type	| ENUM	| Тип операции (parse/optimize/generate/design)	| Категоризация функций |
|status	| ENUM	| Статус выполнения	| Отслеживание прогресса |
|llm_model	| VARCHAR(50)	| Используемая модель ИИ | Отслеживание стоимости |
|prompt_version	| VARCHAR(20)	| Версия промпта | Воспроизводимость |
|input_data	| JSON	| Входные данные для операции | Отладка и анализ |
|output_data | JSON	| Результаты операции | Хранение результатов |
|tokens_used | INT	| Использованные токены	| Расчет стоимости |
|processing_time_ms	| INT | Время выполнения | Метрика производительности |
|cost_estimate	|  DECIMAL(10,6)  |Расчетная стоимость	| Финансовый контроль |

**Индексы**:

- idx_project_id - История операций по проекту

- idx_operation_type - Анализ по типу операции

- idx_status - Мониторинг статусов

- idx_started_at - Анализ времени выполнения

**Связанные сценарии использования**:

- UC1: Загрузка презентации для улучшения (операции optimize, design)

- UC2: Создание новой презентации с нуля (операции generate, design)

|last_accessed	| TIMESTAMP	| Последнее обращение	| Очистка старых записей |

**Индексы**:

- unique_prompt_hash - Уникальность кэшированных ответов

- idx_last_accessed - Удаление неиспользуемых записей

- idx_created_at - Анализ заполнения кэша

## Оптимизация производительности

### Критические индексы для сценариев использования

```sql
-- UC1: Загрузка и оптимизация презентации
INDEX idx_parsing_status (parsing_status) ON PresentationFiles
INDEX idx_project_version (project_id, version_id) ON Slides
INDEX idx_operation_type_status (operation_type, status) ON AI_Operations

-- UC2: Генерация с нуля
INDEX idx_project_status (project_id, status) ON Projects
INDEX idx_slide_type (slide_type) ON Slides
INDEX idx_ai_cache_prompt (prompt_hash) ON AI_Cache

-- UC3: Настройка стиля
INDEX idx_template_category (category, is_active) ON Templates
INDEX idx_project_template (project_id, template_id) ON Projects

-- Общая производительность
INDEX idx_user_created (user_id, created_at DESC) ON Projects
INDEX idx_file_upload (project_id, upload_date DESC) ON PresentationFiles
INDEX idx_export_status (status, created_at) ON Exports
