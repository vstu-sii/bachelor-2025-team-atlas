# Документация по схеме базы данных
## AutoPitch Deck Generator

## Обзор

Эта база данных поддерживает систему автоматической генерации и улучшения питч-презентаций для стартапов. Система интегрируется с Telegram для аутентификации, использует AI (LLM) для оптимизации контента, управляет профессиональными шаблонами дизайна и обеспечивает экспорт в различные форматы.

##Детальные спецификации таблиц
### 1. Таблица Users (Пользователи)
**Назначение**: Хранение учетных записей пользователей, аутентифицированных через Telegram Widget

|Поле	| Тип	| Описание | Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|telegram_id |  BIGINT | Уникальный | идентификатор пользователя Telegram	Первичный ключ аутентификации (UC1, UC2) |
|telegram_username | VARCHAR(255)	| Имя пользователя Telegram с @	| Идентификация пользователя |
|telegram_first_name	| VARCHAR(255)	| Имя пользователя |	Отображение в интерфейсе |
|subscription_tier | ENUM	| Уровень подписки (free/pro/business)	| Определение лимитов и функциональности |
|projects_limit	| INT	| Максимальное количество проектов	| Ограничение по подписке |
|export_limit_daily	| INT	| Дневной лимит экспортов	| Контроль использования |
|created_at	| TIMESTAMP	| Время создания аккаунта	| Аналитика пользователей |
|last_login	| TIMESTAMP	| Последний успешный вход	|  Управление сессиями |
|settings	| JSON	| Настройки пользователя	| Персонализация интерфейса |

**Индексы**:

  - idx_telegram_id - Быстрый поиск пользователей при аутентификации

  - idx_subscription_tier - Фильтрация по уровню подписки

  - idx_created_at - Аналитика роста пользователей

**Связанные сценарии использования**:

  - UC1: Загрузка презентации для улучшения

  - UC2: Создание новой презентации с нуля

  - UC3: Настройка стиля

### 2. Таблица Projects (Проекты)
**Назначение**: Управление презентационными проектами пользователей

|Поле	| Тип	| Описание	| Отношение к сценариям использования |
|--------|---------|------------------------|------------------------------------|
|id	| CHAR(36)	| UUID проекта	| Безопасная идентификация проекта  |
|title	| VARCHAR(255)	| Название проекта	| Отображение в интерфейсе |
|status	| ENUM	| Статус проекта (draft → ready → exported)	| Отслеживание прогресса (UC1, UC2) |
|template_id	| VARCHAR(100)	| Используемый шаблон дизайна	| Применение стиля (UC3) |
|industry	| VARCHAR(100)	| Индустрия стартапа	| AI-рекомендации по шаблонам |
|language	| ENUM	| Язык презентации (ru/en)	| Локализация контента  |
|visibility	|  ENUM	| Видимость проекта	| Контроль доступа |
|last_exported_at	|  TIMESTAMP	| Время последнего экспорта	| История активности |

**Ограничения**:

    - Внешний ключ на Users с каскадным удалением

    - Статус проходит через определенный workflow

**Индексы**:

    - idx_user_id - Быстрая загрузка проектов пользователя

    - idx_status - Фильтрация по статусу проекта

    - idx_created_at - Сортировка по времени создания

    - idx_user_status - Эффективные запросы "проекты пользователя со статусом X"

**Связанные сценарии использования**:

    - UC1: Загрузка презентации для улучшения

    - UC2: Создание новой презентации с нуля

    - UC3: Настройка стиля
