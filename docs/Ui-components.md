## 1. Экран Авторизации 

- Название экрана: Авторизация
- Назначение: Быстрая регистрация и вход через сайт для предпринимателей.

**Макет**:

- Hero-секция с фоновым градиентом и примерами презентаций

- Центрированная карточка авторизации с закруглёнными углами

- Футер с информацией о системе

**Элементы**:

- Логотип: "AutoPitch" в верхней части hero-секции

- Заголовок: "Создавайте питч-деки с AI" с подзаголовком " Презентации- Быстро и Профессионально "

- Widget: Кнопка "Войти "

**Альтернативные варианты**:

- Кнопка "Продолжить как гость" (ограниченный функционал)

- Ссылка "Уже есть аккаунт?" для повторного входа

- Преимущества системы (в виде иконок + текст):

- "AI-оптимизация текста"

- "Профессиональные шаблоны"

- "Экспорт в PPTX/PDF"

**Поведение**:

- При нажатии на "Войти " открывается  Login Widget

- После успешной авторизации - redirect в дашборд с welcome-tour

- "Продолжить как гостю" - доступ к базовым функциям с ограничениями

- В футере - ссылки на условия использования и политику конфиденциальности

## 1.2. Экран Авторизации - Ошибка верификации
- Название экрана: Вход  - Ошибка

- Назначение: Отображение ошибки при неудачной авторизации 

**Макет**:

- Та же структура, что и основной экран авторизации

- Добавлен баннер ошибки поверх карточки авторизации

**Элементы**:

- Баннер ошибки: Красный баннер с иконкой предупреждения и текстом "Ошибка верификации. Попробуйте снова"

- Widget: Перезагруженный виджет

- Кнопка повтора: "Повторить попытку" под виджетом

- Альтернатива: Увеличенная кнопка "Продолжить как гость"

**Поведение**:

- При ошибке верификации показывается баннер

- Кнопка "Повторить попытку" перезагружает  Widget

- Через 3 неудачные попытки предлагается войти как гость

##  2. Дашборд - Основной экран
- Название экрана: Дашборд проектов

- Назначение: Центральный хаб для управления всеми презентациями пользователя

**Макет**:

- Боковая панель навигации слева (фиксированная)

- Основная рабочая область справа

- Верхняя панель с поиском и уведомлениями

**Элементы**:

- **Боковая панель**:

- Логотип "AutoPitch" вверху

- **Навигационные элементы**:

- "Мои проекты" (активно)

- "Шаблоны"

- "Аналитика"

- "Настройки"

- Счетчик проектов: "3/10 проектов" (использовано/лимит)

- **Верхняя панель**:

- Поиск: поле "Поиск по проектам..."

- Уведомления: иконка колокольчика с badge

- Профиль пользователя: аватар + Telegram username

- **Основная область**:

- Заголовок: "Мои презентации"

- Кнопки действий:

- "Создать с нуля" (primary)

- "Улучшить существующую" (secondary)

- Сетка проектов (3 колонки на десктопе)

**Поведение**:

- Нажатие на проект - открытие редактора

- "Создать с нуля" - переход в мастер создания

- "Улучшить существующую" - модальное окно загрузки файла

- Поиск работает в реальном времени

## 2.2. Дашборд - Пустое состояние

**Элементы**:

-- Подзаголовок: "AutoPitch поможет превратить идею в убедительный питч для инвесторов"

- Кнопки действий (горизонтально):

- " Создать с нуля" (большая, с иконкой)

- " Загрузить презентацию" (большая, с иконкой)

-- Быстрые шаблоны: 3 превью популярных шаблонов

**Поведение**:

- Кнопки ведут в соответствующие workflows

- При наведении на шаблон - показ примера результата

- Onboarding tips можно закрыть

## 3. Мастер создания презентации с нуля
- Название экрана: Создание презентации - Шаг 1/5

- Назначение: Пошаговый процесс генерации презентации по описанию идеи

**Макет**:

- Прогресс-бар сверху с номерами шагов

- Центрированная форма текущего шага

- Кнопки навигации "Назад"/"Далее"

**Шаг 1 - Описание идеи**:

- Заголовок: "Расскажите о вашем стартапе"

- Текстовое поле: "Опишите ваш продукт, целевую аудиторию и уникальное предложение..." (многострочное)

- Примеры: Кнопки с примерами описаний

- AI-анализ: В реальном времени показывает "AI анализирует ваш текст..."

**Шаг 2 - Структура презентации**:

- Заголовок: "Выберите разделы для презентации"

- Чеклист (12 вариантов):

-  Титульный слайд

-  Проблема рынка

-  Наше решение

**Шаг 3 - Целевая аудитория**:

- Заголовок: "Кто ваши инвесторы?"

- Варианты: "Венчурные фонды", "Бизнес-агенты", "Краудфандинг", "Гранты"

**Шаг 4 - Шаблон дизайна**:

- Заголовок: "Выберите стиль презентации"

- Галерея шаблонов (3x2 сетка)

-  Фильтры: "Все", "Профессиональные", "Креативные"

**Шаг 5 - Предпросмотр**:

- Заголовок: "Проверьте и настройте"

- Превью: Миниатюры всех слайдов

- Кнопка: " Создать презентацию"

**Поведение**:

- Возможность пропустить любой шаг

- Автосохранение прогресса

- На шаге 5 - мгновенная генерация черновика

## 4. Экран загрузки файла
- Название экрана: Загрузка презентации

- Назначение: Загрузка и анализ существующей презентации для улучшения

**Макет**:

- Модальное окно поверх дашборда

- Drag-and-drop зона по центру

- Информация о поддерживаемых форматах

**Элементы**:

- Заголовок модалки: "Загрузите презентацию для улучшения"

- Drag-and-drop зона:

- Иконка загрузки файла

- Текст: "Перетащите PPTX или PDF файл сюда"

- Или кнопка "Выбрать файл на компьютере"

- Ограничения: "До 100MB. Поддерживаются PPTX и PDF"

** Источники (табы)**:

- "С компьютера"

- "Google Drive"

- "Прямая ссылка"

**Предзагрузочные настройки**:

- "Улучшить текст с помощью AI"

- "Применить профессиональный шаблон"

- Выбор шаблона из выпадающего списка

**Поведение**:

- При перетаскивании файла - подсветка зоны

- После выбора файла - показ превью и начало анализа

- При загрузке по ссылке - поле для URL + кнопка "Загрузить"

- Кнопка "Отмена" возвращает в дашборд

## 4.2. Экран загрузки - Анализ файла
**Название экрана: Анализ загруженной презентации**

**Назначение: Отображение процесса парсинга и AI-анализа файла**

**Макет**:

- Модальное окно с прогресс-баром

- Детальная информация о ходе анализа

- Превью извлекаемых слайдов

**Элементы**:

- Прогресс-бар: 3 этапа:

- Парсинг файла (0-40%)

- AI-анализ контента (40-80%)

- Подготовка рекомендаций (80-100%)

**Детали этапа**:

- "Найден 21 слайд"

- "Анализирую слайд 3: 'Проблема рынка'..."

- "Оптимизирую тексты..."

- Превью слайдов: Миниатюры распознанных слайдов (карусель)

- Предварительные рекомендации: "На слайде 7 слишком много текста"

- Кнопка: "Продолжить в редакторе" (появляется по завершении)

**Поведение**:

- Реальное обновление прогресса

- Возможность прервать анализ

- При ошибке парсинга - предложение альтернативных действий

## 5. Редактор презентаций
**Название экрана: Редактор презентации**

**Назначение: Основной рабочий инструмент для редактирования и дизайна презентаций**

**Макет (трехколоночный)**:

- Левая панель: Миниатюры слайдов + структура

- Центральная панель: Canvas редактора

- Правая панель: Инструменты редактирования

- Элементы левой панели:

- Миниатюры слайдов: Scrollable список всех слайдов

**Кнопки управления**:

- "＋ Добавить слайд"

- "🗑 Удалить"

- "↕ Переместить"

- AI-ассистент: Чат-интерфейс "Спросите AI о слайде..."

**Элементы центральной панели**:

- Canvas редактора: Редактируемый слайд в формате 16:9

- Toolbar поверх canvas:

- Выбор элемента (курсор)

- Текст 

- Изображение 

- Фигуры 

- Диаграммы 

- Режимы просмотра: "Редактирование" | "Предпросмотр" | "Презентация"

**Элементы правой панели (табы)**:

- Дизайн: Цвета, шрифты, шаблоны

- Контент: Редактирование текста текущего элемента

- Анимации: Настройка переходов

**Поведение**:

- Drag-and-drop элементов на canvas

- Редактирование текста в реальном времени

- Автосохранение каждые 30 секунд

-  Горячие клавиши для основных действий

## 5.2. Редактор - AI-рекомендации
- Название экрана: Редактор - AI Рекомендации

- Назначение: Показ и применение AI-предложений по улучшению презентации

**Макет**:

- Правая панель переключена на вкладку "AI-советы"

- Группировка рекомендаций по категориям

**Элементы**:

- Заголовок: "AI Рекомендации для слайда 3"

**Категории**:

- Текст: "Сократите заголовок до 5 слов"

- Структура: "Добавьте буллит-лист вместо абзаца"

- Дизайн: "Используйте более контрастные цвета"

- Данные: "Добавьте график роста выручки"

**Каждая рекомендация содержит**:

- Текст рекомендации

- Кнопки "Применить" / "Отклонить"

П- ример применения (по hover)

**Поведение**:

- "Применить" - мгновенное применение изменения

- "Отклонить" - скрытие рекомендации

- При наведении - показ визуального примера

- Возможность запросить альтернативные варианты

## 7. Экран экспорта
- Название экрана: Экспорт презентации

- Назначение: Настройка и запуск экспорта презентации в различные форматы

**Макет**:

- Модальное окно с выбором опций экспорта

- Превью итогового файла

**Элементы**:

- **Форматы экспорта (radio buttons)**:

- PPTX (редактируемый PowerPoint)

Опции: "С анимациями", "Со всеми шрифтами"

- PDF (для рассылки)

Опции: "Высокое качество", "Сжатый размер", "С интерактивными ссылками"

- Изображения (по слайдам)

Опции: "PNG", "JPG", "Разрешение"

**Дополнительные опции**:

- "Добавить водяной знак AutoPitch"

- "Создать одностраничное резюме (PDF)"

- Поле "Название файла"

**Превью: Первая страница в выбранном формате**

**Кнопки действий**:

- " Скачать сейчас"

- " Сохранить в облако" (Google Drive, Dropbox)

- " Отправить на email"

**Поведение**:

- При выборе формата - мгновенное обновление превью

- Прогресс экспорта для больших файлов

- История экспортов доступна в проекте
